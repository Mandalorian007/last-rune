# Workstream: a11y (wave 5)

**Goal:** the whole game is playable and understandable by keyboard alone, with a screen reader for the menus and story, with reduced motion and Reduce flashes, and without relying on colour alone. Audit first, then fix.

**Owns:** `games/last-rune/ui/` (HUD, settings, codex, fuse caption a11y attributes), DOM a11y in scenes (`aria-*`, roles, focus order, live regions), `engine/ui/` and `engine/input/` (generic only), and a new `tests/e2e/a11y.spec.ts`. Altar and hall visuals only where a colour-only signal needs a shape or text backup; keep those changes small and show screenshots.
**Don't touch:** puzzle rules, story copy (except alt text and labels), and the post or art pipeline beyond the above.

## Deliver
1. **Audit report** (`docs/design/a11y-audit.md`) covering:
   - keyboard-only paths through title, hall, altar, solve, journal, codex, settings, ending and end card;
   - focus visibility and traps;
   - the screen-reader story: what is announced at each step;
   - contrast of all DOM text;
   - colour-only signals: exact/under/over, gem identities, socket states;
   - reduced motion and Reduce flashes coverage;
   - gamepad, if supported;
   - text scaling.
2. **Fix** everything S1/S2 from the audit. Likely candidates:
   - announce strike results and machine needs in a live region;
   - gem identities have shape cues, not only colour (check what's there);
   - visible focus rings everywhere;
   - Esc and Back are consistent.
3. **HUD focus restore.** When a panel closes, `ui.stack` returns focus to the HUD opener, which then swallows arrows and Enter. The game blurs the button as a workaround (see the comment in `games/last-rune/ui/hud.ts`). Fix it properly in the engine:
   - either an option to not restore focus to HUD openers,
   - or Input treating arrows, Enter and Space as global on non-text buttons.
   Then remove the workaround.
4. **`tests/e2e/a11y.spec.ts`:** run axe-like checks with a small in-repo checker. No new network deps; a pnpm devDependency is fine if it's well known and offline, such as `@axe-core/playwright`. Also cover keyboard focus order and the live region text for a strike.

`pnpm check`, `pnpm build` and `pnpm test:e2e` must pass.
