# Workstream: last-rune-desktop (Phase 4, parallel with port-chrome)

Plan: [../engine/refactor-plan.md](../engine/refactor-plan.md), "Phase 4" → ws/last-rune-desktop. Decision: D-042 (Electron; saves stay in localStorage; unsigned builds).

## Scope
- Last Rune boots with `createElectronHost()` when `window.thunderclap` is present, and with the web host otherwise. Wire this through `createGame`'s host option. Keep the game's own code free of Electron imports outside one boot seam.
- **Settings: a desktop-only Quit entry** using `host.window.close`.
  - port-chrome is porting the settings panel at the same time. Keep your change to one small additive entry, gated on `ctx.host.window`, so the merge is easy.
- Links (Ko-fi, Discord, itch) and fullscreen already go through the host. Verify that they work in the shell.
- **Desktop build:**
  - `pnpm desktop:build` with the Last Rune renderer (`--renderer dist`), product name "The Last Rune" and app id `com.thunderclap.lastrune` (or similar);
  - a procedural app icon generated by a script (no image assets, per CLAUDE.md). It must be generated, not hand-drawn.
- **e2e:** Playwright's Electron driver runs title → intake-desk → solve, plus a save surviving a relaunch.
- **CI:** the desktop job builds Last Rune artefacts. Leave it non-blocking for now.

## Not in scope
- Signing.
- File storage.
- Any scene layout work (that is port-chrome's).

## Rules
- The web build is unchanged: `pnpm baseline` 129/129, and the itch zip is byte-identical apart from the boot seam.
- Commit to `ws/last-rune-desktop` and never merge.
- Before reporting, run `pnpm check`, `pnpm build`, `pnpm baseline`, `pnpm test:e2e`, `pnpm test:e2e:engine`, `pnpm test:e2e:desktop` and a macOS `pnpm desktop:build`.
