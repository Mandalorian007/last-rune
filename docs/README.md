# docs/ — project management hub

This folder tracks all work on **The Last Rune**. The project manager (Claude, PM agent) owns it. Workstream agents update their own workstream file and report back. The PM merges everything else.

| File | Purpose |
|---|---|
| [PLAN.md](PLAN.md) | Roadmap: milestones with state, wave plan, user feedback backlog, known engine gaps. PM updates it on every merge and every piece of user feedback |
| [STATUS.md](STATUS.md) | Live board: what's in flight, done, blocked |
| [DECISIONS.md](DECISIONS.md) | Decision log (ADR-lite). Any deviation from the pitch goes here |
| [architecture.md](architecture.md) | Module boundaries, contracts between workstreams, engine promotion rule |
| [engineering.md](engineering.md) | Tooling, conventions, branch/worktree/merge workflow, definition of done |
| [design/pitch-v0.3.md](design/pitch-v0.3.md) | Canonical design pitch (verbatim import) |
| [design/](design/) | Derived design specs: rules, progression, puzzles, art direction |
| [workstreams/](workstreams/) | One brief + log per workstream/agent |
| [research/](research/) | Research notes (itch.io, WebGPU support, etc.) |
| [shipping-itch.md](shipping-itch.md) | Retired (D-047): old itch.io runbook, kept for reference |
