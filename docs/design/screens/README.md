# Screenshots

Only `playtest/` lives here. `docs/design/playtest-report.md` uses those images.

Older workstream screenshots (art, altar, hall, props, ending, polish-1, caption-layout and others) were removed before v1.0 to keep the public repo small. They are still in git history. To browse them:

    git checkout a5c9705 -- docs/design/screens

New screenshots go in `docs/design/screens/local/`, which git ignores. Describe what you saw in your workstream log; don't commit images. If a picture is really needed in a doc, commit one small JPG (≤300 KB) and ask the PM first.
